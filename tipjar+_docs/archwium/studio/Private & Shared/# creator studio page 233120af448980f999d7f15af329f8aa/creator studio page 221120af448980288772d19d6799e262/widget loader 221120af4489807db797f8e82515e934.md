# widget loader

✅ `widget.js` gotowy – skrypt do osadzania na dowolnej stronie:

- Tworzy `iframe` z osadzonym widgetem TipJar+
- Ładuje `https://tipjar.plus/widget/preview?handle=...`
- Osadza się w prawym dolnym rogu, z wysokim z-index

---

Przykładowe użycie na stronie twórcy:

```html
html
KopiujEdytuj
<script src="https://tipjar.plus/widget.js" data-creator="janKowalski"></script>

```

Co dalej? Animacja przy pojawieniu? Obsługa niestandardowych stylów z widgetStore?

// public/widget.js
(function () {
const script = document.currentScript;
const creator = script.getAttribute('data-creator') || 'me';
const iframe = document.createElement('iframe');

iframe.src = `https://tipjar.plus/widget/preview?handle=${creator}`;
iframe.style.border = 'none';
iframe.style.width = '200px';
iframe.style.height = '60px';
iframe.style.position = 'fixed';
iframe.style.bottom = '20px';
iframe.style.right = '20px';
iframe.style.zIndex = '9999';
iframe.allowTransparency = true;

document.body.appendChild(iframe);
})();
